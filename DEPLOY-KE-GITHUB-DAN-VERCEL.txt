DEPLOY SINGKAT

1. Upload seluruh isi folder ini ke repository GitHub.
2. Di Vercel pilih Import Project dari repository tersebut.
3. Framework: Next.js. Build command: npm run build.
4. Deploy.

PENTING: v2.0 memakai IndexedDB lokal sebagai penyimpanan default. Artinya data tidak otomatis tersinkron antar perangkat. Untuk operasi multi-user/multi-device, hubungkan adapter database cloud pada backend sebelum produksi.
